# Celta-Force / chest-rush
Game concept
The player is not a traditional turret builder. Instead, they are a mobile weapon platform:

fixed party of 3 "鬼" companions
each spirit acts like a passive weapon with its own behavior and stats
the player moves, dodges, and gathers loot while the weapons fight automatically
the real challenge is not just damage output, but pacing and survival
The core loop is:

enter a haunted fragment
defeat enemies in waves
collect key relics
escape through the gate before the domain escalates

You can see the specific details in the.thought/0.design.md
