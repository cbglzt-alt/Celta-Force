# 搜打撤游戏核心玩法极简设计要点

## 一、核心玩法极简描述（纯对局底层规则）

游戏为固定关卡式搜打撤玩法，采用保卫萝卜4式多主题固定关卡设计，各关卡拥有专属地图布局、场景地貌与怪物特性，同时配备固定专属开局装备体系与道具刷新规则，关卡地形、怪物刷新点位全部固定可预判。地图所有障碍、宝箱均可摧毁，稳定掉落金币与各类道具；地图固定点位以**固定计时为轮次**周期性刷新怪物，区别于清怪结算轮次，场上怪物无需清空、可持续留存叠加，且怪物整体数值随计时轮次稳步增强，倒逼玩家在持续搜集资源的同时及时提升对局战力。为杜绝玩家刻意留存任务道具、无限刷轮不撤离的投机死循环，本局所需搜集任务道具与普通道具均藏在宝箱中。不同关卡拥有专属怪物特性，且与本局固定开局装备形成精准克制适配，强制玩家结合关卡特质制定专属对战、搜集与撤离策略。局内金币仅用于**本局临时强化**开局装备与道具数值，强化成本逐级递增且设有等级上限，对局结束后所有本局强化效果清零。玩家初始仅3格视野，存在场景视野遮蔽（参考保卫萝卜4迷雾机制），可通过消耗型视野道具拓展视野范围一次一格，墙体障碍永久遮挡视野，摧毁障碍、宝箱需多次攻击。地图设有多条差异化撤离通路，各通路区分怪物密度、障碍数量与物资分布，玩家需完成指定搜集任务方可解锁撤离点权限；搜集任务完成后，场上怪物数值（攻击速度和行动速度）会大幅暴涨，同时开启固定时长高压撤离倒计时，超时未撤离则本局直接失败，最终形成「隐蔽搜集发育—计时抗怪提战—限时高压撤离」的完整、无漏洞的专属对局闭环。
