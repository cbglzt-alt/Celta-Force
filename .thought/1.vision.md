# Chest Rush · 一页纸定位

> 依据 `.thought/godot/0.recipe.md` 模板。世界观见 `0.story.md`，阶段目标见 `2.next_phase.md`。本文是后续所有取舍的基准。

## 定位六问

**玩家是谁，扮演谁**
诡异复苏都市里的**驭鬼者**：以自身为牢笼驾驭恶鬼，穿过「门」潜入鬼域碎片，轻装快节奏，靠走位与发育判断取胜。

**玩家每局最主要做什么**
开局携带 3 只己方鬼（被动自动作战），在固定布局的鬼域里砸箱搜刮金币与关键道具；用金币做局内强化抬上限，在敌方波次不断涌现、稳步变强的压力下，找齐关键道具后冲向「门」撤离。

**最有吸引力的矛盾或取舍**
**火力成长曲线 vs 怪物增强曲线**——何时强化、捡什么、敢不敢去更远的箱子。搜得越狠塔越强，但滞留越久敌压越高；策略在发育节奏，不在「撤不撤」。

**一局预计多长**
5–10 分钟，适配碎片化游玩。

**希望玩家反复体验的情绪**
移动塔发育的掌控感、波次压迫下的走位紧张、搜齐穿门的释放，以及「这局曲线我压得更漂亮」的再来一局。

**本项目明确不做什么（当前阶段）**
多关卡地图、选关界面、叙事美术、可视化地图编辑器、联网。单关手感与数值曲线未稳前，不开长线系统的大工。

## 一句话定位

披着搜打撤外壳的塔防：驭鬼者以 3 鬼为被动火力、以自身为移动塔，在鬼域中比拼成长曲线，搜齐关键遗物后穿门撤离。

## 灰盒原型关键决策（仍有效）

- **表现层**：纯色块 + 中文 HUD，无美术资产；验证「好玩」而非「好看」。
- **操作**：WASD/方向键移动；3 鬼自动索敌开火；Q 用视野道具；1/2/3 买强化（抬上限并补满）；R 结算后重开。掉落物触碰自动拾取。
- **地图**：40×24 格 ASCII 定义；墙 `#` 永久遮挡视野，障碍 `o` 可摧毁（存活时挡视野），宝箱 `C` 多段攻击摧毁；撤离点 =「门」。
- **迷雾**：三态（未探索/已探索/可见），初始视野半径 3 格，BFS 蔓延、墙体阻挡；怪物与掉落物仅在可见格显示。
- **战斗与波次**：被动攻击；波次在玩家周围环形随机涌现，数量先缓后陡。
- **强化**：攻 / 速 / 血三线，费用递增；生命强化 = 抬上限并一次补满。
- **通关**：集齐 3 个关键道具 → 撤离解锁 → 踩门离开。关键道具带出后可作跨关永久成长（长线支柱，见 `2.next_phase.md`）。

## 灰盒验证记录（2026-07-28）

- 地图数据校验：24×40，出生点 → 两个撤离点连通，20 宝箱 / 障碍全部脚本校验可达。
- 无头 soak：被动攻击 + 随机涌现下多波追击接触，无脚本/运行错误。
- 渲染检查：实机截图确认三态迷雾、中文 HUD、相机跟随、3 鬼槽位与环绕标记正常。
- 已知取舍：相机不设硬边界（地图外显示为纯黑，与未探索迷雾融为一体）。
- 工程备注：新增/重命名全局 `class_name` 后需先跑一次 `godot --headless --editor --quit` 刷新类缓存；`--quit-after N` 是帧数不是秒数；物理 flush 内不创建/销毁碰撞体（用 `call_deferred` / `set_deferred`）。

## 待真人试玩判断

1. 被动攻击是否真让「移动塔」成立（只管走位与搜刮的爽感）。
2. 后期波次陡增是刺激还是劝退；搜齐后撤离窗口是否够。
3. 强化抬上限 + 补满是否有「明显变强」实感。
4. 3 只鬼定位是否清晰；是否想要更多鬼 / 换关组合。
5. 3 格视野 + 迷雾是紧张还是憋屈；Q 视野道具价值感如何。
6. 失败时（被击倒 / 压不过曲线）是否能立刻明白原因。
