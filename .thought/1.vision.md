# Chest Rush · 一页纸定位（Phase 1）

> 依据 `.thought/godot/0.recipe.md` Phase 1 模板。本文不超过一页，是后续所有取舍的基准。

## 定位六问

**玩家是谁，扮演谁**
一名独自深入封锁区的寻宝者。轻装、快节奏、靠判断而不是操作取胜。

**玩家每局最主要做什么**
在一张固定布局的地图里砸开宝箱搜集金币与任务道具，用金币做局内临时强化，在怪物按计时轮次不断增援、稳步变强的压力下，找齐任务道具后冲向撤离点。

**最有吸引力的矛盾或取舍**
“要不要再多搜一个箱子？”——贪婪与生存的持续心算。搜得越久越强，但场上一怪不请自来、只增不减；任务完成那一刻全场暴走，搜集期积累的优势必须在 75 秒内兑现成一次成功的撤离。

**一局预计多长**
5–10 分钟，适配碎片化游玩。

**希望玩家反复体验的情绪**
隐蔽发育的紧张感、倒计时冲刺的心跳、压哨撤离的释放感，以及“这次我能贪得更漂亮”的再来一局。

**本项目明确不做什么（当前阶段）**
背包/装备树、多关卡、永久成长与图鉴、剧情、存档、联网、美术资产与音频。核心循环未经试玩验证前，一律不开工。

## 一句话定位

低操作负担、重路线判断的搜索撤离游戏：玩家在逐渐失控的关卡中搜集资源，决定何时放弃贪心并活着离开。

## 灰盒原型（Phase 2）关键决策记录

- **表现层**：纯色块 + 中文 HUD（系统字体微软雅黑），无美术资产；验证“好玩”而非“好看”。
- **操作**：WASD/方向键移动，鼠标瞄准 + 左键/空格近战挥击；Q 用视野道具；1/2/3 买强化；R 结算后重开。掉落物触碰自动拾取。
- **地图**：40×24 格 ASCII 定义；墙 `#` 永久遮挡视野，障碍 `o` 可摧毁（存活时挡视野），宝箱 `C` 多段攻击摧毁；撤离点 2 处（东路怪多而近、南路绕远而稀），刷怪点 `S` 固定。
- **迷雾**：三态（未探索/已探索/可见），初始视野半径 3 格，BFS 蔓延、墙体阻挡；怪物与掉落物仅在可见格显示。
- **闭环数值初版**：轮次间隔 20s，每轮 HP×1.15、速度+3%；宝箱 10+ 个，随机 3 个藏任务道具（外表一致）；集齐 3 个 → 撤离解锁 + 全场暴走（速×1.8、攻速×2）+ 75s 倒计时；强化三线（攻/速/血）费用 30×1.6^级、各上限 4 级。

## 待试玩验证的假设

1. 3 格视野 + 迷雾是否制造“信息不足的紧张”而非“憋屈”。
2. 75s 倒计时的松紧是否让撤离段既刺激又可达。
3. 无寻路追击 AI 在灰盒地图上是否足够形成压力（预期会卡在墙角，可接受范围内）。
4. 强化三线的定价与收益是否让玩家真的纠结金币怎么花。
5. 3 分钟内是否能自然产生 3 次以上“继续搜 / 现在撤”的判断。

## 灰盒验证记录（2026-07-28）

- 地图数据校验：24×40，出生点 → 两个撤离点连通，20 宝箱 / 12 刷怪点 / 17 障碍全部脚本校验可达。
- 无头 soak：5 倍速约 92 秒游戏时间（4 波刷怪、追击、接触战斗），无脚本/运行错误。
- 渲染检查：实机截图确认三态迷雾、中文 HUD（SystemFont 微软雅黑）、相机跟随正常。
- 已知取舍：相机不设硬边界（地图外显示为纯黑，与未探索迷雾融为一体）；怪物无寻路，可能被墙卡——待试玩判断是否可接受。
- 工程备注：新增/重命名全局 `class_name` 后需先跑一次 `godot --headless --editor --quit` 刷新类缓存，否则直接运行会报 “Identifier not declared”；`--quit-after N` 是帧数不是秒数。

## 试玩清单（对照验收标准）

1. 完整打一局：砸箱 → 攒钱买强化（1/2/3）→ 找齐 3 个任务道具 → 75 秒内踩到绿色撤离点。
2. 3 分钟内是否做出 ≥3 次「继续搜 / 现在撤」的判断？
3. 失败时（超时 / 被击倒）是否能立刻明白原因？
4. 3 格视野是紧张还是憋屈？Q 视野道具的价值感如何？
5. 怪物压力是否足够？卡墙是否影响体验？
6. 强化定价是否让人纠结金币怎么花？
