# Chest Rush · 故事与设定素材库（借鉴《神秘复苏》）

> 用途：为「移动塔 + 3 鬼装备 + 搜道具穿门撤离」提供有血有肉的世界骨架。  
> 原则：**借气质与机制骨架，不照搬原文专名做商业成品**；下文中的名称可作内部代号，上线前可再起游戏内正式名。  
> 玩法锚点以 `2.next_phase.md` 为准：主角是会移动的塔；每关开局 3 只「己方鬼」自动作战；场上「敌方鬼」按波次涌现；搜齐关键道具后穿「门」撤离。

---

## 〇、一句话世界

诡异复苏的架空现代都市里，普通人看不见规则，**驭鬼者**以自身为牢笼，驾驭恶鬼换取力量，再穿过「门」潜入**鬼域碎片**（关卡），搜集能压制复苏的关键遗物——代价是：每用一次力量，体内的鬼就更清醒一分。

## 一、可直接落地的世界观骨架

### 1.1 核心概念（建议全部做成系统词条）

| 概念 | 小说气质 | 游戏建议 |
|---|---|---|
| **复苏** | 鬼越用越醒，最终反噬宿主 | 局内「复苏条」：过度强化/长时间滞留会抬高敌方波次强度，或让己方鬼进入「失控预警」 |
| **驾驭** | 人把鬼关进身体当武器 | = 装备栏；3 鬼槽位；换关=换组合 |
| **鬼域** | 鬼展开的异空间/污染区 | = 关卡本体；迷雾、腐朽贴图、视野压缩都是鬼域表现 |
| **鬼奴** | 死者被鬼域收编，形似生前无理智 | = 低级杂兵模板；长得像人但行为僵硬；击杀掉「鬼钱」（局内强化材料） |
| **门** | 通往异空间/事件的通道 | = 撤离点；也可做成敲门鬼召唤的「假门」陷阱 |
| **触发条件 + 杀人规律** | 每只鬼有固定触发与手法 | = 敌人机制说明书；玩家靠观察学克制，而不是无脑输出 |
| **级别 C/B/A/S** | 按危害范围分，不等于单体强度 | = 关卡威胁标签 + Boss 标签；C 驻守、B 游走、A 区域控场、S 关底灾难 |

**级别落地建议（与波次曲线挂钩）**

- **C 限制级**：固定刷点/低移速杂兵，适合教学关。  
- **B 危险级**：可游走、会扩散（分裂/传染印记），中期压力源。  
- **A 灾难级**：带「区域规则」（定身、换头、伤害转移），精英/小 Boss。  
- **S 毁灭级**：关底或限时事件 Boss，改变整张图规则（时间回卷、全图饥饿、全图入梦等）。

### 1.2 故事背景（定调，不必做成冗长剧情）

- 世界表面正常，暗处已有「国际刑警式」驭鬼组织在归档、收容、派人送死。  
- 主角不是圣人救星，是**想活命、想变强、顺便把世界从崩坏里往回拽一点**的实用主义者。  
- 每关「鬼蜮」= 某次灵异事件残留的碎片：学校、商场、荒村、公交、酒店……关卡主题直接来自事件。  
- 关键道具 = 组织档案里记载的「能钉住鬼 / 骗过鬼 / 换一次死」的遗物（棺材钉、鬼烛、替死娃娃、人皮纸碎片等气质）。

**玩法融入**：开局 10 秒字幕/电台旁白即可；长叙事放图鉴与通关后解锁档案，不打断 5–10 分钟对局。

## 二、你已提出的五鬼：原著对位 + 平衡与玩法建议

> 你的设想已经很贴「移动塔」；下面补原著味道、克制关系、以及和 3 鬼槽位的搭配。

### 2.1 敲门鬼（敌 · A 灾难级 · 高血）

**原著骨架**：黑衣老人不推门，只按固定节奏敲门；敲门声触发诅咒式死亡；可展开鬼域；能制造大量鬼奴。

**你的设计（保留）**  
游走地图 → 面前凭空出「门」→ 敲击 → 当前区域低于其等级的单位（含主角与低级敌鬼）定身 5s → 定身结束全体掉血。

**建议打磨**

| 点 | 建议 |
|---|---|
| 压迫感 | 敲门前 1.5s 有「门框浮现 + 咚咚预告」音频，给走位窗 |
| 等级差 | 「低于自身等级才定身」很好；主角可用局内强化临时抬「抗敲门等级」 |
| 友军误伤 | 定身也作用于敌方低级鬼 → 可做成「用敲门鬼清场但自己也挨刀」的风险收益 |
| 克制 | 草绳吊起打断敲门读条；替身把掉血转给小怪；饿死鬼在定身结束瞬间吞掉它召唤的鬼奴 |
| Boss 变体 | 敲第 3 下改为「展开临时鬼域」：该区域迷雾加深、视野-1，持续 8s |

**关卡角色**：中后期精英 / 区域控制器；出现时迫使玩家离开当前搜刮点。

---

### 2.2 草绳鬼 / 鬼绳（己方开局武器 · 低级起，可成长）

**原著骨架**：无形鬼寄生草绳，无征兆勒颈；绑住则厉鬼也难挣脱；宿主自己也被绳子反勒（双刃剑）。

**你的设计（保留）**  
吊起周围若干敌鬼，定身 + 持续扣血；每秒伤害 ∝ 草绳强化级 vs 目标级别。

**建议打磨**

| 点 | 建议 |
|---|---|
| 手感 | 自动索敌优先「血量最低 / 正在读条的精英」 |
| 上限 | 同时吊起数 = 1+强化级；对 A 级以上只能吊、不能秒，强调控场 |
| 双刃剑风味 | 满层强化后偶发「反勒」：主角短时移速下降，换更高 DPS |
| 组合 | 吊起 → 换头鬼偷能力；吊起 → 饿死鬼安全进食 |

**定位**：近中距控场件，教玩家「先控后打」。

---

### 2.3 替身鬼（敌 · A · 高血高攻 + 伤害转移）

**原著气质**：替身/替死、勒死后被取代、镜中鬼需替身现身等——「死转移到别人身上」。

**你的设计（保留）**  
被动把受到的伤害转移到周遭敌鬼；设转移上限以平衡。

**建议打磨**

| 点 | 建议 |
|---|---|
| 可读性 | 受伤时有「黑线弹向附近小怪」；小怪头顶显示「替」标记 |
| 上限 | 每秒可转移伤害有 cap；或转移次数满后硬直 2s（破防窗） |
| 克制 | 先清光周围小怪再单吃；或用草绳把小怪吊离其半径 |
| 变体 | 「完美替身」：死亡时附身最近一只小怪满血复活一次（仅一次） |

**关卡角色**：教玩家「拆挂件再打本体」的精英。

---

### 2.4 饿死鬼（己方开局武器 · 高级宠 · 成长）

**原著骨架**：鬼婴寄生→破体→吃人成长；可吃鬼；S 级事件源头；甚至涉及时间重启。

**你的设计（保留）**  
主角身边一只「可爱」饿死鬼，主动冲去吃敌鬼；越吃越强。

**建议打磨**

| 点 | 建议 |
|---|---|
| 反差萌 | 视觉可爱，吃的时候露出诡异大口（恐怖喜剧） |
| 成长 | 吃 C→小幅永久（本局）伤；吃 B→攻速；吃 A→解锁「啃精英」但进食时间变长 |
| 风险 | 进食中定身；若被敲门鬼定身打断则吐出来并掉层成长 |
| S 级彩蛋（后期） | 成长满后短时「小重启」：把最近 5s 内主角受到的伤害回滚一次（CD 很长） |
| 平衡 | 不能吃替身鬼本体（或吃了只吃到被转移的那份），避免无脑克制 |

**定位**：发育型核心；鼓励「清小怪养宠」与「保宠不被打断」。

---

### 2.5 换头鬼 / 假模特（己方开局武器 · 中级）

**原著骨架**：商场无头假模特拼装躯体；从背后换头；被换头者本人不知自己已是鬼；正对则无法换头。

**你的设计（保留）**  
击杀敌鬼有概率「换头」，短时间获得该鬼能力。

**建议打磨**

| 点 | 建议 |
|---|---|
| 触发 | 击杀时 % 概率 |
| 时长 | 8–12s；同时只能持 1 个头（新头覆盖旧头） |
| 表现 | 换头鬼外观变成「无头模特 + 敌人的头」 |
| 风味规则 | 对「背对玩家的敌人」额外提高换头成功率（奖励走位） |
| 组合 | 偷到敲门鬼的「敲门」可反制一波；偷到替身的转移可当肉盾期 |

**定位**：娱乐性最高的变招件；图鉴收集欲强。

---

### 2.6 推荐开局三角（验证用）

与 `2.next_phase.md` 的「3 鬼差异清晰」对齐，建议第一关固定：

1. **草绳鬼**（控）  
2. **饿死鬼**（成长输出）  
3. **换头鬼**（变招）  

敌方教学精英：**替身鬼**；中后期插入：**敲门鬼**。

## 三、从原著可再挖的「鬼」清单（按游戏可用性排序）

> 每条格式：级别建议｜原著能力骨架｜敌/己｜玩法融入

### 3.1 优先做成关卡怪物 / Boss

#### 鬼奴（C）
- **能力**：人形杂兵，无理智冲锋。  
- **玩法**：敲门鬼/鬼域 Boss 的召唤物；死亡掉「鬼钱」（局内强化材料，用于抬上限/强化己方鬼）。  
- **融入**：让 A 级 Boss「有挂件」，替身鬼周围永远不缺转移目标；同时是稳定的鬼钱来源。

#### 鬼婴（C→B，可成长）
- **能力**：接触触发；啃咬叠「被盯上」印记；长大后形态变青年/可开小鬼域。  
- **玩法**：被盯上后可消失一段时间，再次出现时成长为下一阶段，逼迫玩家及时击杀，不能拖。  
- **融入**：饿死鬼的「食物链」叙事——己方饿死鬼专克鬼婴。

#### 换头模特群（B）
- **能力**：站桩转头；仅攻击玩家背面；被盯着则不动。  
- **玩法**：强制相机/走位游戏；背对密集区=自杀。  
- **融入**：商场关主题怪；与己方换头鬼形成镜像梗。

#### 身后脚步（B）
- **能力**：玩家移动时在身后生成不可见压迫；停止移动则靠近并攻击。  
- **玩法**：停走越久，受到的攻击伤害越高；与「移动塔」核心操作强绑定。  
- **融入**：迷雾关杀手；可用草绳吊住「声音源」显形。

#### 倒影鬼（A）
- **能力**：镜面/水洼中的倒影攻击实体；打碎所有反射面才露真身。  
- **玩法**：先砸场景反射物（可交互箱/镜），再输出。  
- **融入**：酒店/卫生间主题关；视野道具可「照出倒影」。

#### 遗像鬼 / 黄岗「模仿」残响（A~S）
- **能力**：压制其他鬼能力；或整张地图「模仿」成正常村落后突然翻脸。  
- **玩法**：周期性让己方 3 鬼沉默 3s；或伪装成宝箱/NPC。  
- **融入**：荒村关 Boss；克制「无脑堆装备」。

#### 梦魇（A/S 事件）
- **能力**：睡着则死；无实体。  
- **玩法**：关卡规则「禁止站桩过久」——静止 >N 秒进入梦境条，满则巨伤。  
- **融入**：与移动塔哲学一致；强化「一直在动」。

#### 鬼来电（B 规则怪，慎用）
- **能力**：铃声响则死（因果律气质）。  
- **玩法**：不要做成必杀；改成「场上随机响铃，响铃时全员受伤，找到电话亭砸掉则停」。  
- **融入**：都市街道关事件波。

#### 许愿鬼（A，双刃）
- **能力**：满足愿望但收代价。  
- **玩法**：可选事件：立即满血/加攻击，但下一波敌人 +50% 或复苏条大涨。  
- **融入**：赌徒型玩家的趣味开关；别做成唯一最优解。

#### 鬼差（A/S）
- **能力**：执法/勾魂气质，专门针对「驭鬼者」。  
- **玩法**：优先追杀主角，无视小怪；对己方鬼伤害加成。  
- **融入**：多关长线「通缉度」Boss。

#### 画中鬼 / 鬼画（S 气质）
- **能力**：把人拖进画中世界。  
- **玩法**：踩到画幅区域被吸入「画中副本」小房间，限时打出出口。  
- **融入**：美术馆/老宅关；增加节奏变化。

#### 灵异公交（场景 Boss）
- **能力**：车厢即鬼域，门不开则循环。  
- **玩法**：关卡在移动车厢内；到站开门=临时安全区；错站=更难车厢。  
- **融入**：竖向或分段地图，天生适合「搜齐 3 道具下车」。

### 3.2 优先做成己方装备 / 道具鬼

| 名称 | 定位 | 自动攻击表现 | 备注 |
|---|---|---|---|
| **无头鬼影** | 近战斩击/抓取 | 阴影之手劈向最近敌 | 原著杨间第二鬼气质；可作「刀」的正式皮 |
| **鬼眼** | 真视/弱点 | 周期性暴露敌弱点（受伤+25%） | 对假模特、倒影、替身特攻 |
| **鬼烛（道具）** | 保命光环 | 点燃后 N 秒无敌或极高减伤，烧尽留虚弱 | 局内一次性，别当常驻武器 |
| **替死娃娃（道具）** | 免死 | 挡一次致命伤害后碎裂 | 跨关永久成长线可升级次数 |
| **人皮纸（危险装备）** | 吞鬼回能 | 击杀时概率吞残魂回血，但复苏条↑ | 高手向 |
| **棺材钉（关键道具）** | 钉死 Boss | 对关底使用可跳过狂暴阶段 | 正好对接「搜 3 个关键道具」 |

**事件波（可插入任意关）**

1. **敲门夜**：60s 内每隔 15s 尝试敲门。  
2. **换头促销**：全场模特起立。  
3. **饥饿潮**：鬼婴数量翻倍，饿死鬼进入狂吃（攻速↑但易被打断）。  
4. **铃声**：砸掉 3 台「该死的电话」否则持续掉血。  
5. **入梦**：静止条出现，强迫keep moving。

## 五、关键地图原型（几何 + 叙事一体）

> 不必一次做完；每张图一个「规则关键词」即可。

1. **腐朽教学楼**：长走廊 + 多教室口袋；关键词「门」。死路教室可能刷假门。  
2. **歇业商场**：环形中庭 + 服装店模特林；关键词「朝向」。  
3. **雾中荒村**：开阔但视觉差；关键词「模仿」。宝箱可能是假的。  
4. **夜班公交**：细长多节车厢；关键词「站点」。撤离=正确到站门。  
5. **镜酒店**：对称房间；关键词「倒影」。打破镜子改变连通。  
6. **地下停尸/医院**：房间多、门多；关键词「寄生」。鬼婴从尸体袋出。  

**与现有原型衔接**：继续用固定 ASCII/网格关；主题先换刷怪表与事件脚本，美术后补。

## 六、主角性格（可玩的人格，不是小说复印）

### 6.1 建议人格关键词

**冷静、嘴贱、务实、记仇但不立刻发作、把活命放第一、把规则研究当乐趣。**

原著杨间气质可借：  
- 恐惧时仍强迫自己分析规律；  
- 不装英雄，敢收「封口费」也敢救人；  
- 对羞辱能忍，对鬼与对算计自己的人毫不手软；  
- 幽默是减压阀（饿死鬼「可爱」路线很贴这点）。

### 6.2 游戏里怎么「演」出来（低成本）

- **短句旁白**：进门「又是这种地方。」；敲门预告「别应门。」；撤离成功「赚到了。」  
- **行为反馈**：受辱式失败文案不煽情（「死了。下次别站着发呆。」）。  
- **选择味**：许愿事件选项永远带代价，符合其「没有免费的善意」。

主角不必叫杨间；可用「档案代号：鬼眼」一类组织称呼，保持借鉴距离。

## 七、关键人物（作 NPC / 电台 / 图鉴，不抢对局）

| 角色原型 | 性格 | 游戏用途 |
|---|---|---|
| **接线员**（刘小雨型） | 专业、紧绷、偶尔吐槽 | 关卡开始任务简报；警告下只鬼的触发条件 |
| **老刑警/前辈**（周正型） | 燃尽式责任感 | 教学关「残响」：短暂助战 NPC 塔，随后倒下留装备 |
| **聪明人牺牲品**（方镜型） | 冷静到残忍 | 反面教程：教「别学他坑队友」；或其留下的陷阱宝箱 |
| **组织上司**（赵建国型） | 利益与编制优先 | 多关解锁：发布悬赏、定义关卡 A/S 标签 |
| **研究者**（王小明型） | 冷静到不近人情 | 卖「分析」：展示本关鬼的克制提示（花鬼钱） |
| **同僚竞争者**（赵开明型） | 傲慢、实力强 | 竞速/挑战模式影子；或抢关键道具的干扰 AI |
| **普通人同事/同学** | 怕、拖后腿、也是人性 | 可选护送事件（加分但增压）——慎用，避免破移动塔手感 |

**原则**：对局中最多「电台声音」；立绘与长对话放在关间与图鉴。

## 八、系统设计建议：让设定变成「血肉」

### 8.1 每只鬼的统一数据字段（方便以后加内容）

```
id / 显示名 / 级别(C-S) / 阵营(己/敌)
触发条件(文案+代码)
行动规律(巡逻/索敌/读条)
命中效果(伤害/控制/规则)
克制标签[] / 被克制标签[]
复苏代价(己方用)
图鉴故事(短)
```

### 8.2 己方 3 鬼的搭配哲学

- 一控（草绳） / 一成长（饿死） / 一变招（换头）——新手。  
- 一探（鬼眼） / 一斩（鬼影） / 一域（范围）——信息局。  
- 双输出 + 保命道具——竞速局。  

关卡「专属开局 3 鬼」继续保留：用克制讲故事（商场关强制带鬼眼）。

### 8.3 敌方精英的设计口诀

**看得见的规则 > 数值膨胀。**  
敲门要听得见；换头要看朝向；替身要看见转移线；饿死要看见进食。

### 8.4 长期成长（对接关键道具）

带出道具解锁：  
- 图鉴条目（新怪/新己方鬼）  
- 开局装备池扩容  
- 永久抗性（抗敲门、抗换头、抗入梦）  
- 外观：饿死鬼皮肤、模特换头皮肤

## 十、写作与合规备注（给未来的自己）

- 本文是**机制与气质借鉴笔记**，商业发布需全面重命名、重写文案与原创美术。  
- 恐怖喜剧路线（可爱饿死鬼、嘴贱主角）可降低「纯惊悚」疲劳，更贴移动塔爽感。  
- 任何「因果律必杀」进游戏都必须改成**可交互、可反制的规则事件**，否则会毁塔防手感。

## 十一、一页纸总结

**世界**：驭鬼者钻门入鬼域，搜遗物压复苏。  
**主角**：冷静务实的移动塔，三鬼自动打，人只负责走位与贪心。  
**五柱鬼**：敲门（区域控场敌）、草绳（控场己）、替身（转移敌）、饿死（成长己）、换头（变招己）。  
**关卡**：一事件一规则（门/朝向/模仿/站点/倒影）。  
**人物**：电台式组织网，不进对局抢操作。  
**成功标准**：玩家能说出「这关的鬼规矩是什么」，并且觉得用规矩虐鬼很好玩。
