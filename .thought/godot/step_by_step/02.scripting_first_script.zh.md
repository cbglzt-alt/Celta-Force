# 创建你的第一个脚本（Creating your first script）

> 原文：`godot-docs/getting_started/step_by_step/scripting_first_script.rst`

本篇用 GDScript 写第一个脚本，让 Godot 图标转圈移动。教程假设你**已有编程基础**（你有 Java 经验，符合）。

配图（最终效果）：`img/scripting_first_script_rotating_godot.gif`

> 想深入 GDScript 语法，见官方 GDScript 章节。本篇只教 GDScript，不涉及 C#。

## 项目准备

新建一个干净项目（或在 `chest-rush` 里单独做练习场景）。项目里需要有一张图：**Godot 图标** `icon.svg`（社区里常用来做原型）。

配图：`img/scripting_first_script_icon.svg`

### 创建 Sprite2D 节点

1. 在 **Scene** 面板点 **Other Node**
2. 搜索 `Sprite2D`，双击创建

配图：`img/scripting_first_script_click_other_node.webp` → `add_sprite_node.webp`

Scene 面板里现在应该只有一个 `Sprite2D` 节点。

### 设置纹理

Sprite2D 需要 **Texture** 才能显示。Inspector 里 Texture 显示 `<empty>` 时：

- 从 **FileSystem** 把 `icon.svg` **拖**到 Texture 槽上

配图：`img/scripting_first_script_setting_texture.webp`

> 提示：也可以直接把图片拖到视口，自动创建 Sprite2D。

在视口里拖动图标，把它居中。

配图：`img/scripting_first_script_centering_sprite.webp`

## 创建并挂载脚本

1. 在 Scene 面板**右键** `Sprite2D`
2. 选 **Attach Script（附加脚本）**

配图：`img/scripting_first_script_attach_script.webp`

在 **Attach Node Script** 窗口：

- **Template** 从 `Node: Default` 改成 **`Object: Empty`**（从空白文件开始）
- 其他保持默认，点 **Create**

配图：`img/scripting_first_script_attach_node_script.webp`

Script 工作区会打开 `sprite_2d.gd`，第一行是：

```gdscript
extends Sprite2D
```

### `extends` 是什么意思？

每个 GDScript 文件隐式是一个**类**。`extends Sprite2D` 表示这个脚本**继承** `Sprite2D` 节点，因此能访问 Sprite2D 及其父类（`Node2D`、`CanvasItem`、`Node`）的属性和方法。

> 若省略 `extends`，类会隐式继承 `RefCounted`（内存管理用），一般挂到节点上的脚本都要写 `extends 某节点类型`。

Inspector 里看到的属性（如 `texture`）都可以在脚本里读写。

> **命名对照**：Inspector 里常用 **Title Case**（如 `Texture`）；代码里用 **snake_case**（如 `texture`）。鼠标悬停属性名可看代码里的标识符。

## Hello, world!

脚本现在什么都不做。先让它在底部 **Output** 面板打印 `Hello, world!`：

```gdscript
func _init():
    print("Hello, world!")
```

### 代码说明

- `func` — 定义函数
- `_init` — **构造函数**，节点/对象在内存中**被创建时**引擎会自动调用（若你定义了它）

> GDScript **靠缩进**表示代码块。`print()` 前面必须有 Tab 或空格缩进，否则报错 "Indented block expected"。

保存场景为 `sprite_2d.tscn`，按 **F6** 运行，看底部 **Output** 是否出现 `Hello, world!`。

配图：`img/scripting_first_script_print_hello_world.webp`

然后**删掉** `_init()` 函数，只保留 `extends Sprite2D`。

## 让图标旋转

在 `extends Sprite2D` 下面添加两个**成员变量**：

```gdscript
var speed = 400          # 移动速度（像素/秒）
var angular_speed = PI   # 角速度（弧度/秒）
```

成员变量写在 `extends` 之后、函数之前。每个挂了这个脚本的节点实例，都有自己独立的 `speed` 和 `angular_speed`。

> Godot 里角度默认用**弧度**。也有转角度的辅助函数。

### `_process(delta)` — 每帧更新

游戏以很多**帧（frame）** 每秒循环渲染画面，常用 **FPS（帧率）** 衡量，多数游戏目标 60 FPS。

每帧耗时会有微小波动，所以引擎提供 **`delta`**：上一帧到这一帧经过的**秒数**。用 `delta` 做位移，运动才与帧率无关。

在脚本**底部**添加：

```gdscript
func _process(delta):
    rotation += angular_speed * delta
```

- 以 `_` 开头的函数是 Godot **虚函数/内置回调**，供引擎调用
- `rotation` 继承自 `Node2D`，单位是**弧度**

按 **F6** 运行，图标应原地旋转。

配图：`img/scripting_first_script_godot_turning_in_place.gif`

> 在代码编辑器里 **Ctrl + 点击**（macOS：**Cmd + 点击**）`rotation`、`_process` 等，可打开官方文档。

## 向前移动

在 `_process` 里、`rotation += ...` **下面**再加两行（缩进对齐）：

```gdscript
var velocity = Vector2.UP.rotated(rotation) * speed
position += velocity * delta
```

### 代码说明

| 代码 | 含义 |
|------|------|
| `var velocity = ...` | 函数内的**局部变量**，只在本函数有效 |
| `Vector2.UP` | 向上方向的单位向量 |
| `.rotated(rotation)` | 按当前旋转转成「图标朝向」的前方 |
| `* speed` | 得到带速度的速度向量 |
| `position += velocity * delta` | 更新节点位置（`position` 是 `Vector2` 类型） |

运行后，Godot 头像会边转边绕圈走。

配图：`img/scripting_first_script_rotating_godot.gif`

> 这种直接改 `position` 的移动**不会**检测墙壁碰撞。在 `first_2d_game` 教程里会学带碰撞的移动方式。

下一篇 **scripting_player_input** 会用玩家输入控制移动。

## 完整脚本参考

```gdscript
extends Sprite2D

var speed = 400
var angular_speed = PI


func _process(delta):
    rotation += angular_speed * delta

    var velocity = Vector2.UP.rotated(rotation) * speed

    position += velocity * delta
```

## 本篇你要记住的概念

| 概念 | 一句话 |
|------|--------|
| `extends` | 脚本挂在哪种节点上，就 extends 谁 |
| `_init()` | 创建时调用（构造） |
| `_process(delta)` | 每帧调用（游戏循环） |
| `delta` | 帧间隔秒数，做移动必乘它 |
| `rotation` / `position` | 继承自 Node2D 的旋转与位置 |
