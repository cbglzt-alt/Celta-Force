# 节点与场景（Nodes and Scenes）

> 原文：`godot-docs/getting_started/step_by_step/nodes_and_scenes.rst`

在 Godot 简介里我们说过：一个 Godot 游戏是一棵**场景树**，每个场景本身也是一棵**节点树**。本篇会进一步说明，并带你创建第一个场景。

---

## 节点（Nodes）

**节点是游戏最基本的组成单位**，像菜谱里的食材。Godot 有几十种节点：显示图片、播放声音、代表摄像机，等等。

配图：`img/nodes_and_scenes_nodes.webp`

所有节点都有这些共性：

- 有**名称**
- 有可编辑的**属性**
- 每帧会收到**更新回调**
- 可以**扩展**新属性和函数
- 可以作为**子节点**挂到别的节点下

最后一点很重要：**节点组成树形结构**，这是组织项目的强大方式。不同节点功能不同，组合起来就能做出更复杂的行为。

例如， playable 角色 + 相机跟随，可以用这些节点拼出来：

- `CharacterBody2D` — 角色物理体
- `Sprite2D` — 显示精灵图
- `Camera2D` — 摄像机
- `CollisionShape2D` — 碰撞形状

配图：`img/nodes_and_scenes_character_nodes.webp`

---

## 场景（Scenes）

把节点组织成树（比如上面的角色），这个整体就叫**场景**。保存后，场景在编辑器里就像一种**新的节点类型**，可以拖到别的场景里当子节点用；此时它看起来是一个节点，内部结构被折叠隐藏。

场景让你按任意方式组织代码。你可以**组合节点**，造出自定义复杂类型，例如：会跑会跳的角色、血条、可交互的宝箱，等等。

配图：`img/nodes_and_scenes_3d_scene_example.webp`

Godot 编辑器本质上就是**场景编辑器**，有编辑 2D/3D 场景和 UI 的大量工具。一个项目可以有任意多个场景，但引擎只需要**一个主场景（main scene）**——运行游戏时 Godot 首先加载它。

除了像普通节点一样使用，场景还有这些特点：

1. 始终有**一个根节点**（例如例子里的 "Player"）
2. 可以**保存到磁盘**，以后加载
3. 可以**实例化任意多份**（比如从同一个 Character 场景生成 5～10 个角色）

---

## 创建第一个场景

我们先做一个只含单个节点的场景。你需要先**新建项目**（或打开现有项目如 `chest-rush`），打开后是空编辑器。

配图：`img/nodes_and_scenes_01_empty_editor.webp`

空场景时，左侧 **Scene（场景）** 面板会提供快速添加根节点的选项：

| 按钮 | 添加的根节点 |
|------|-------------|
| **2D Scene** | `Node2D` |
| **3D Scene** | `Node3D` |
| **User Interface** | `Control` |
| **Other Node** | 自选任意节点作为根节点 |

这些预设只是方便；不是必须的。**Other Node** 在空场景里，等价于点 Scene 面板左上角的 **Add Child Node（添加子节点）**。

我们要加一个 **`Label`** 节点，用来在屏幕上绘制文字。

1. 点 **Add Child Node** 或 **Other Node**
2. 在 **Create New Node** 对话框里搜索并选中 **Label**
3. 点 **Create**

配图：`img/nodes_and_scenes_02_scene_dock.webp` → `03` → `04` → `05`

添加第一个节点后会发生很多事：因为 Label 是 2D 节点，工作区切到 2D；Label 出现在视口左上角并被选中；Scene 面板显示节点树；右侧 Inspector 显示属性。

---

## 修改节点属性

把 Label 的 **Text** 属性改成 `"Hello World"`：

1. 在右侧 **Inspector** 里找到 **Text**
2. 在输入框里输入 `Hello World`

配图：`img/nodes_and_scenes_06_label_text.webp`

输入时视口会实时显示文字。

> 提示：Inspector 里列出的属性大多可以直接改。详见官方 Inspector 文档。

用工具栏的**移动工具**可以拖动 Label：

配图：`img/nodes_and_scenes_07_move_tool.webp`

选中 Label 后，在视口里拖拽，把它移到矩形区域中间。

配图：`img/nodes_and_scenes_08_hello_world_text.webp`

## 运行场景

点右上角 **Run Current Scene（运行当前场景）**，或按 **F6**（macOS：**Cmd + R**）。

配图：`img/nodes_and_scenes_09_play_scene_button.webp`

会弹出保存场景对话框——**必须先保存才能运行**。在文件浏览器里点 **Save**，保存为 `label.tscn`。

配图：`img/nodes_and_scenes_10_save_scene_as.webp`

> **Save Scene As** 等对话框只能把文件保存在**项目内**。窗口顶部的 `res://` 表示项目根目录，即「资源路径」。

新窗口会打开，显示 "Hello World"。

配图：`img/nodes_and_scenes_11_final_result.webp`

关闭窗口或按 **F8**（macOS：**Cmd + .**）退出运行。

---

## 设置主场景

刚才用的是 **Run Current Scene（运行当前场景）**。旁边还有 **Run Project（运行项目）**，用来设置并运行项目的**主场景**，快捷键 **F5**（macOS：**Cmd + B**）。

配图：`img/nodes_and_scenes_12_play_button.webp`

> **运行主场景**和**运行当前场景**不是一回事。行为不对时，先确认跑的是哪个场景。

第一次点 **Run Project** 会弹出选择主场景的窗口：

配图：`img/nodes_and_scenes_13_main_scene_popup.webp`

点 **Select**，在文件对话框里双击 `label.tscn`。

配图：`img/nodes_and_scenes_14_select_main_scene.webp`

之后每次 **F5** 运行项目，都会从这个场景开始。

> 主场景路径保存在 `project.godot` 里。也可以在 **Project → Project Settings → Application → Run → Main Scene** 中设置。

## 本篇你要记住的三句话

1. **节点** = 功能积木；**场景** = 保存好的一棵节点树。
2. **`res://`** = 项目根目录；场景文件扩展名是 **`.tscn`**。
3. **F6** 跑当前场景，**F5** 跑主场景——两个快捷键别混。
