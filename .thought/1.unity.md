# Unity 入门 Recipe（搜打撤项目专用）

> 本手册是一份**可勾选的执行清单**，不是阅读材料。每一步都给出「做什么 / 验收标准 / 预计耗时」。按顺序做完，你就能动手写本项目（《搜打撤》核心玩法）的第一个可玩原型。
>
> 适用对象：有 Java/其他语言编程基础、但没碰过 C# 和 Unity 的开发者。
> 总预算：**约 3 周**（第 1 周 C#，第 2 周 Unity 基础，第 3 周 mini 项目）。

## 阶段 1：纯 C# 热身（1 周，不碰 Unity）

> 为什么先不碰 Unity？Unity 编辑器界面 + C# 语法 + 游戏开发思维三件事**一起学**很容易过载。先在纯控制台里把 C# 写顺，进 Unity 后你才能把注意力放在游戏逻辑上，而不是被语法绊住。C# 和 Java 像，但生态、细节（属性、LINQ、事件、`async`）差别不小。

**只用一个文件 + 命令行就能练**，避免被 IDE 分心：

```bash
# 安装 .NET SDK：https://dotnet.microsoft.com/download
dotnet new console -o HelloCsharp
cd HelloCsharp
dotnet run
```

按顺序做完下面 5 个小练习，**每个都写完、跑通、能解释为什么**再进下一个：

- [ ] **① Hello / 类型 / if / 循环**：打印 1~100，能被 3 整除打印 `Fizz`，能被 5 整除打印 `Buzz`，都能整除打印 `FizzBuzz`。
  - *验收*：理解 `int` / `string` / `bool`、`if-else`、`for`、`%` 取模。
- [ ] **② 类与方法**：写一个 `Player` 类，有 `Name`、`Hp`、`MaxHp` 字段，方法 `TakeDamage(int)`（不低于 0）和 `Heal(int)`（不超过 MaxHp）。
  - *验收*：理解 `class`、字段 vs 属性（`{ get; set; }`）、`public/private`、构造函数。
- [ ] **③ 集合与 LINQ**：生成 20 个随机数，用 LINQ 一行筛出大于 50 的、排序、求和。
  - *验收*：理解 `List<T>`、`Dictionary<K,V>`、`using System.Linq;`、`.Where().OrderBy().Sum()`。
- [ ] **④ 猜数字游戏**：随机一个 1~100 的数，玩家循环输入，提示"大了/小了"，猜中显示次数。
  - *验收*：理解 `Console.ReadLine()`、`int.Parse`、`Random`、`while` 循环、异常 `try/catch`。
- [ ] **⑤ 事件 / 委托（Unity 必备）**：给 `Player` 加一个 `event Action<int> OnDamaged`，`TakeDamage` 时触发它，外部订阅打印日志。
  - *验收*：理解 `delegate` / `event` / `Action<T>` / `+=` 订阅 —— **Unity 里 UI 点击、碰撞回调全是这套机制**，提前掌握收益巨大。

**资源**：
- 官方 C# 教程（免费、可在线运行）：https://learn.microsoft.com/dotnet/csharp/tour-of-csharp/
- 速查（语法对照 Java→C#）：搜 "C# for Java developers cheat sheet"

**判断"够了"的标准**：不看文档能徒手写出 ④⑤，且能解释属性、事件、LINQ。

## 阶段 2：Unity 基础（1 周）

### 2.1 第一个项目 + 让方块动起来（1~2 天）

- [ ] 在 Hub 新建项目，选 **3D (URP)** 模板（URP 是现代推荐管线，本项目的 2D 俯视角也用它更省心）。
- [ ] 认识 5 个核心窗口，**对得上名字**即可：
  - `Hierarchy`（场景里有哪些对象）、`Scene`（3D 视图）、`Game`（运行时玩家看到的画面）、`Inspector`（选中对象的所有组件）、`Project`（项目文件/资源）。
- [ ] 在场景里 `右键 → 3D Object → Cube`。
- [ ] `Project 窗口 → Create → C# Script`，命名 `PlayerController`，双击用 VS 打开，写：

```csharp
using UnityEngine;

public class PlayerController : MonoBehaviour  // 继承 MonoBehaviour 才能挂到对象上
{
    public float speed = 5f;  // public = 在 Inspector 里可调

    void Update()  // 每帧调用一次
    {
        float x = Input.GetAxis("Horizontal");  // A/D 或 ←/→
        float z = Input.GetAxis("Vertical");    // W/S 或 ↑/↓
        transform.Translate(x * speed * Time.deltaTime,
                            0,
                            z * speed * Time.deltaTime);
    }
}
```

- [ ] 把这个脚本**拖到 Cube 上**（= 给这个 GameObject 挂一个 Component）。
- [ ] 按 ▶ 运行，用 WASD 控制方块移动。

**验收**：能解释 `MonoBehaviour` / `Update` / `Time.deltaTime`（为什么乘它）/ `Input.GetAxis`。能说清"脚本就是挂在 GameObject 上的一个组件"。

### 2.2 理解 Unity 的核心心智模型（半天）

把这一段**读懂**再往下走，这是 Unity 一切的地基：

> **万物皆 GameObject，GameObject 是空容器，功能全靠挂 Component。**
>
> - `Transform`：位置/旋转/缩放（每个对象必须有，不能删）。
> - `Mesh Renderer` / `Mesh Filter`：显示一个 3D 模型。
> - `Collider`：碰撞体（不可见，决定"撞到没"）。
> - `Rigidbody`：物理（受重力、可被推）。
> - **你写的 `: MonoBehaviour` 脚本**：自定义行为。
>
> 你写的脚本里 `transform`、`gameObject` 这些字段，就是"我这个脚本所挂在的那个对象"的引用。

### 2.3 官方入门项目：Roll a Ball（3~4 天）

跟着官方教程做完一个**完整、有开始有结束**的小游戏，这是新手获得成就感和完整流程认知的最佳路径：

- [ ] 打开教程：搜 **"Unity Roll a Ball tutorial"**（官方，约 2~3 小时视频，建议跟着敲，别只看）。
- [ ] 完成后你应该有：一个能控制的球、可拾取的方块、计分 UI、胜利提示。
- [ ] **额外加练**（强制，本项目用得上）：
  - [ ] 加一个"敌人"方块会追着玩家跑（用 `Vector3.MoveTowards`）。
  - [ ] 碰到敌人扣血 / 游戏结束（学会 `OnCollisionEnter` / `CompareTag`）。
  - [ ] 加一个倒计时，超时失败。

**验收**：能徒手新建脚本挂上去，会用 `Instantiate`（生成对象）、`Destroy`（销毁）、`OnCollisionEnter`（碰撞检测）、简单 UI（`Text` / `TMP`）。

## 阶段 3：本项目衔接（第 3 周）

做完阶段 2，你已经具备读官方文档和实现玩法的能力。回到本项目（见 `0.design.md` 的核心玩法），按这个顺序拆出**最小可玩原型（MVP）**，砍掉一切非核心：

- [ ] **① 地图与视野**：用 Tilemap 或方块拼一张固定地图；实现"墙体遮挡视野"——用 `Collider` + 一个遮罩 / `SpriteMask` 模拟迷雾，初始 3 格视野。
- [ ] **② 玩家移动 + 攻击**：移动复用阶段 2 的 `PlayerController`；攻击用射线（`Physics2D.Raycast`）或扇形范围判定，可摧毁墙体/宝箱（多次攻击累加伤害）。
- [ ] **③ 宝箱与掉落**：宝箱有 HP，被打碎 `Instantiate` 掉落金币/道具 prefab。
- [ ] **④ 怪物与计时轮次**：固定点位定时 `Instantiate` 怪物；用一个 `Timer` 脚本，每隔 N 秒"轮次 +1"，全场怪物属性乘以倍率。
- [ ] **⑤ 撤离闭环**：搜集任务道具 → 解锁撤离点 → 触发"高压倒计时"（怪物数值暴涨）→ 走到撤离点胜利 / 超时失败。
- [ ] **⑥ 局内强化**：用金币在简化 UI 上升级开局装备（攻击/速度），对局结束清零（用一个 `RunState` 静态变量管理）。

> **新手忠告**：MVP 阶段**全部用方块和圆**，不要碰美术、音效、动画。能玩起来 > 好看。所有数字（视野格、轮次时间、怪物倍率）用 `public` 字段挂到 Inspector，方便随手调。

## 速查：Unity 必踩的 8 个坑

1. **脚本类名必须和文件名完全一致**，否则挂不上去。
2. **新建脚本挂上去显示 "Missing"**？多半是类名/文件名不一致，或编译有错（先看 Console）。
3. **Console 报错先看红色**，黄色警告可暂时忽略；报错里双击能跳到对应代码行。
4. **改了脚本但运行时没生效**？检查你是不是在 Play 模式（▶ 亮着）下改的 —— **退出 Play 模式再改**，否则改动不保存。
5. **`public` 字段才出现在 Inspector**；想序列化私有字段用 `[SerializeField] private`。
6. **找不到组件引用**用 `GetComponent<T>()` 或在 `Inspector` 里拖拽赋值（`public T xxx;`）。
7. **`Update` 里别用 `new` 狂建对象**（GC 压力），也别每帧 `Find("名字")`（慢）；在 `Start` 里缓存引用。
8. **预制体（Prefab）**：把 Hierarchy 里的对象拖到 Project 窗口就变成 Prefab，等于"对象模板"，`Instantiate(prefab)` 就能克隆一个 —— 本项目的怪物/宝箱/道具掉落全靠它。
