# Chest Rush · 下一阶段设计校正（试玩后，2026-07-28）

> 来源：灰盒原型实际试玩反馈。本文校正 `1.vision.md` 中过时的假设，并定义下一阶段。
> 旧文保留作历史记录，冲突处以本文为准。

## 一、游戏本质的重新定位

**这游戏是一个披着搜打撤外壳的塔防：主角就是一座会移动的塔。**

- 不存在「继续搜 / 现在撤」的贪撤博弈——那是上一版假设，试玩证伪。
- 真正的核心循环：**被动攻击 → 数值比拼 → 在怪物变强前搜齐 3 个关键道具 → 穿过"门"撤离**。
- 策略不在"撤不撤"，在"**火力成长曲线 vs 怪物增强曲线**"：发育节奏、强化时机、捡什么、敢不敢去更远的箱子。

## 二、背景设定（定调用，不做叙事内容）

- 诡异横行的架空世界（借鉴《神秘复苏》气质）。
- 主角是驭"鬼"人，穿过"门"进入鬼蜮搜集关键道具，提升实力拯救世界。
- **每关开局携带 3 个"鬼"** = 3 个被动攻击装备，每只鬼是一种攻击能力。
- 鬼蜮中的怪物是各种能力的"鬼"，主动袭击主角。
- 关键道具 = **跨关卡的长期成长资源**（搜齐带出后可永久强化自身）。

## 三、试玩确认的硬改动（下一阶段必做）

1. **被动攻击**：移除手动攻击键。武器/鬼自动索敌、自动开火。玩家只管走位与搜刮。这是"移动塔"成立的根基。
2. **怪物原地随机产生**：波次在玩家周围随机位置涌现，每波数量明显提升，压迫感递增。
3. **强化改为抬上限**：局内金币强化 = 提升上限且立即补满（如买生命 → 上限+N 并一次回满），感知要强，告别挤牙膏。
4. **修复后期数值崩塌**：当前强化收益远落后于后期怪物增强，后期难度过高。重做成长曲线，保证强化能跟上波次强度。
5. **3 鬼装备制**：每关固定开局 3 个攻击装备（3 只鬼），装备组合随关卡固定、体现克制适配。

## 四、跨关卡长期成长（新支柱，衔接多关卡）

- 关键道具带出后可**跨关卡永久强化自身属性**。
- 这把"单关闭环"升级为"多关长线"：搜集不再只是通关条件，还是成长投资。
- 与 `0.design.md` 的「通关解锁全局图鉴与全新开局装备」「收集成就长线留存」一脉相承。

## 五、下一阶段目标（Phase：装备即数据 + 单关手感重做）

**最小可验证目标**：一关内，3 只数据驱动的"鬼"自动作战，数值曲线后期不崩，玩家能感到"我的塔在变强"。

暂不做：多关卡地图、选关界面、叙事美术、可视化地图编辑器。

### 任务卡（recipe 模板）

```
目标：被动攻击 + 3鬼装备 + 强化抬上限 + 曲线不崩的一关
假设：被动攻击让"移动塔"成立；强化抬上限修复后期；随机涌现制造压迫
最小实现：
  - 武器/鬼抽象为数据（伤害/冷却/射程/弹道/命中效果）
  - 自动索敌 + 自动开火，删手动攻击
  - 波次随机涌现 + 数量递增曲线
  - 强化改抬上限+补满，重调成长曲线
  - 3 只差异明确的鬼（如：近战弧 / 直线弹 / 范围）
验收：
  - 玩家全程不点攻击键，只走位
  - 打到第 8+ 波仍可通过强化维持战力（后期不崩）
  - 强化每次购买有"明显变强"的实感
  - 3 只鬼打法定位清晰可辨
结论：保留 / 修改 / 删除 / 延后（试玩后填）
```

### 实现回填（2026-07-28 完成后，待试玩）

已按"先爽后紧"定调实现：

- **被动攻击**：删手动攻击键与鼠标瞄准；玩家只走位+承伤。`weapon.gd`（class_name Weapon）数据驱动，3 只鬼挂玩家：
  - `刀` SLASH 近战弧 22 伤/0.55s/60 程（近身群伤）
  - `矢` BOLT 直线弹 16 伤/0.5s/240 程（远程单体，`projectile.gd`）
  - `域` AURA 范围灼烧 7 伤/0.9s/85 程（贴身群伤，带紫色光圈提示）
- **自动索敌**：各鬼独立冷却，射程内找最近敌人自动开火；3 鬼环绕玩家显示彩色标记，HUD 左中实时显示 `名字 当前伤害`。
- **波次涌现**：弃用固定刷怪点，改玩家周围 220px 环形随机位置（避墙）。数量曲线先缓后陡：`3 + 波次 + max(0, 波次-6)`（1波4只/6波9只/8波14只/10波20只）。
- **强化抬上限+补满**：攻击=全体鬼伤害×1.35^级、移速×1.15^级、生命上限+40并一次补满；费用增速 1.6→1.45、上限 4→6 级。
- **曲线重调**：敌 hp_growth 1.15→1.12、speed_growth 1.03→1.02。前中期强化占优给爽感，7 波起数量陡增压向撤离。

### 验证记录

- 无头 5 倍速 soak 240 秒（约 11 波）零报错。
- 桌面截图确认：3 鬼槽位（刀22/矢16/域7）、环绕标记、AURA 光圈、强化文案"生命上限"、中文正常。
- **修了一个物理 flush 崩溃**：弹体命中→敌死→掉落在物理回调内创建碰撞体报 "Can't change this state while flushing queries"。解法：敌死/宝箱掉落/弹体释放统一 `call_deferred` / `set_deferred`，延迟到物理步外创建或销毁碰撞体。

### 待真人试玩判断

1. 被动攻击是否真让"移动塔"成立（玩家只管走位的爽感）。
2. 后期陡增（7 波起）是刺激还是劝退；搜齐后撤离窗口是否够。
3. 强化抬上限+补满是否有"明显变强"实感。
4. 3 只鬼定位是否清晰；是否想要更多鬼/换鬼组合（→ 衔接多关卡装备克制）。
